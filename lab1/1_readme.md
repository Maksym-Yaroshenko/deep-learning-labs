## 1. Математичний опис, розмірності та проміжні значення

Нехай $N = 105$ — кількість об'єктів навчальної вибірки, $D = 4$ — кількість ознак, $H = 8$ — розмір прихованого шару, $C = 3$ — кількість класів. Усі обчислення виконуються у форматі `float64`.

Архітектура мережі:

$$
X \rightarrow \text{Linear}(4, 8) \rightarrow \text{ReLU} \rightarrow \text{Linear}(8, 3)
$$

### Прямий прохід (Forward Pass)

1. Перший афінний шар:
   

   $$
   Z_1 = X W_1 + b_1
   $$

2. Функція активації $\text{ReLU}$:
   

   $$
   A_1 = \max(0, Z_1)
   $$

3. Другий афінний шар (логіти трьох класів):
   

   $$
   Z_2 = A_1 W_2 + b_2
   $$

4. Чисельно стабільний $\text{Log-Softmax}$ зі зсувом на максимум рядка $m_i = \max_j (Z_2)_{i,j}$:
   

   $$
   \tilde{Z}_{2} = Z_2 - m, \quad \text{LogProbs}_{i,c} = (\tilde{Z}_2)_{i,c} - \ln \sum_{j=1}^{C} \exp\left((\tilde{Z}_2)_{i,j}\right)
   $$

5. Функція втрат (крос-ентропія, усереднена за об'єктами):
   

   $$
   L = -\frac{1}{N} \sum_{i=1}^{N} \text{LogProbs}_{i, y_i}
   $$

### Збережені проміжні значення (`cache`) та їх призначення

Під час прямого проходу зберігаються такі проміжні масиви, необхідні для обчислення градієнтів на зворотному проході:

* $X \in \mathbb{R}^{105 \times 4}$ — стандартизована матриця вхідних ознак, потрібна для обчислення градієнта ваг першого шару $dW_1 = X^T dZ_1$.

* $y \in \{0, 1, 2\}^{105}$ та $\text{LogProbs} \in \mathbb{R}^{105 \times 3}$ — необхідні для відновлення матриці ймовірностей $P = \exp(\text{LogProbs})$ та обчислення градієнта функції втрат за логітами $dZ_2$.

* $Z_1 \in \mathbb{R}^{105 \times 8}$ — доактиваційні значення першого шару, потрібні для формування бінарної маски похідної $\text{ReLU}$: $\mathbb{I}(Z_1 > 0)$.

* $A_1 \in \mathbb{R}^{105 \times 8}$ — вихід прихованого шару після $\text{ReLU}$, необхідний для обчислення градієнта ваг другого шару $dW_2 = A_1^T dZ_2$.

### Формули зворотного проходу (Backward Pass)

1. Градієнт за логітами $Z_2$ (де $Y \in \{0, 1\}^{105 \times 3}$ — one-hot представлення істинних міток $y$):
   

   $$
   P = \exp(\text{LogProbs}), \quad dZ_2 = \frac{\partial L}{\partial Z_2} = \frac{1}{N}(P - Y)
   $$

2. Градієнти параметрів другого шару:
   

   $$
   dW_2 = \frac{\partial L}{\partial W_2} = A_1^T dZ_2, \quad db_2 = \frac{\partial L}{\partial b_2} = \sum_{i=1}^{N} (dZ_2)_{i,:}
   $$

3. Поширення градієнта на прихований шар та через $\text{ReLU}$:
   

   $$
   dA_1 = \frac{\partial L}{\partial A_1} = dZ_2 W_2^T, \quad dZ_1 = \frac{\partial L}{\partial Z_1} = dA_1 \odot \mathbb{I}(Z_1 > 0)
   $$

4. Градієнти параметрів першого шару:
   

   $$
   dW_1 = \frac{\partial L}{\partial W_1} = X^T dZ_1, \quad db_1 = \frac{\partial L}{\partial b_1} = \sum_{i=1}^{N} (dZ_1)_{i,:}
   $$

### Розмірності проміжних масивів і чотирьох градієнтів

| Величина | Розмірність | Опис | 
| ----- | ----- | ----- | 
| $X$ | $(105, 4)$ | Стандартизована навчальна вибірка | 
| $y$ | $(105,)$ | Вектор істинних міток класів | 
| $Z_1, A_1, dA_1, dZ_1$ | $(105, 8)$ | Проміжні стани та градієнти прихованого шару | 
| $Z_2, \text{LogProbs}, P, dZ_2$ | $(105, 3)$ | Логіти, логарифми ймовірностей, ймовірності та градієнт за логітами | 
| $W_1, dW_1$ | $(4, 8)$ | Матриця ваг першого шару та її градієнт | 
| $b_1, db_1$ | $(8,)$ | Вектор зсувів першого шару та його градієнт | 
| $W_2, dW_2$ | $(8, 3)$ | Матриця ваг другого шару та її градієнт | 
| $b_2, db_2$ | $(3,)$ | Вектор зсувів другого шару та його градієнт |

## 3. Перевірка окремих градієнтів чисельним диференціюванням

Для кожного параметра $\theta_i$ використано центральну скінченну різницю з кроком $\epsilon = 10^{-6}$:

$$
g_{\text{num}, i} = \frac{L_{+} - L_{-}}{2\epsilon}
$$

Критерій проходження для кожного параметра: $\vert{}g_{\text{num}} - g_{\text{manual}}\vert{} \le 10^{-7}$.

## 4. Дослід із навмисною помилкою

У цьому досліді тимчасово прибрано ділення на кількість об'єктів $N = 105$ у градієнті за логітами $dZ_2$, залишивши функцію втрат та еталонні перевірки незмінними.

Команда відтворення досліду:

```
uv run python lab1/main.py --buggy

```

### Прогноз перед запуском

1. **Чи зміниться втрата на тих самих параметрах:** Ні, значення втрати $L$ не зміниться, оскільки прямий прохід (`forward`) залишається незмінним.

2. **Як зміняться ненульові градієнти:** Через лінійність усіх подальших операцій зворотного проходу відсутність ділення на $N = 105$ масштабує кожен наступний градієнт. Усі ненульові елементи градієнтів $dW_2, db_2, dW_1, db_1$ зростуть за модулем рівно у $105$ разів (обчислюватиметься градієнт суми втрат замість усередненої втрати).

3. **Які перевірки мають виявити помилку:** Помилку мають виявити **обидві** перевірки для всіх чотирьох градієнтів (як звірка з PyTorch autograd, так і чисельне диференціювання), тоді як перевірка самої втрати $L$ пройде успішно.

### Зіставлення з прогнозом та висновки

* **Основна реалізація:** Ручне зворотне поширення похибки в NumPy повністю збіглося з еталоном PyTorch autograd (максимальна різниця порядку $10^{-17}\text{–}10^{-16} \le 10^{-12}$) та підтверджене чисельним диференціюванням (похибка порядку $10^{-11}\text{–}10^{-10} \le 10^{-7}$).

* **Дослід із помилкою:** Прогноз повністю підтвердився. Значення втрати $L$ не змінилося і пройшло перевірку, натомість усі ручні градієнти збільшилися рівно у $105$ разів (наприклад, для $W_1[0,0]$: $-0.0199201843 \times 105 \approx -2.0916193547$). Обидва методи перевірки — і PyTorch autograd, і чисельні похідні — надійно виявили помилку масштабування у зворотному проході.
